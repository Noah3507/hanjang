# 14단계 후속 검토 목록

13단계의 사용자 실사용·로컬 파일 검토에서 정리한 후보입니다. 구현 승인이나 디자인 시스템 재설계 문서가 아니며 이번 PR에서 템플릿·모델을 변경하지 않습니다.

| 항목 | 확인 근거 / 후속 작업 | 담당·승인 기준 |
| --- | --- | --- |
| 한국어 줄바꿈 | 실제 다운로드에서 상품명 마지막 한 글자와 본문 어미가 다음 줄로 분리됨. 현재 `.text { overflow-wrap:anywhere }` 및 제목 폭 제한 확인. 단어 보존·레이아웃 후보·폭 조정을 비교하고 말줄임/삭제 없이 긴 상품명 테스트 | A 서비스/렌더러, 디자인 검토 후 적용 |
| 제목·사진 위계 | 긴 편집 제목의2줄 배치와 상품 사진·큰 흰 프레임·정보 블록 균형을 비교. 상품 형태/색/로고 보존, 원본 또는 처리본 선택 유지 | A, 실제 결과 시각 승인 필요 |
| CTA·연락처 밀도 | CTA의 반복 느낌표와 주소/연락처가 하단에 함께 표시되는 사례. 생성 문구와 사용자 편집/사실 정보의 출처를 구분해 검토 안내. 사용자 입력을 자동 교정·생략하지 않음 | A, 사실 동일성 회귀 |
| 네 전략의 문구 차별성 | 감성/가격/비주얼/브랜드 간 의미 중복·모호한 표현을 별도 비교. 이번 단일 다운로드만으로 네 전략의 우열을 주장하지 않음 | A, 승인된 예제 묶음·사람 평가 |
| 조사 규칙 확대 | 이번에는 가격·상품명 경계의 을/를·은/는·이/가·과/와·으로/로 및 일부 복합 조사만 처리. 영문·숫자 발음 추측 금지, 불확실하면 중립 문형/검토 필요. 인용부호·독특한 상표·추가 복합 조사 corpus 검토 | A, 무료 fixture로 검증 후 확대 |
| 사용자 편집의 사실 검토 | 수량·효능 등 편집자가 추가한 표현의 근거를 확인할 수 있도록 검토 안내. 임의 삭제나 수량 자동 생성 금지 | A, 사용자 사실·편집 출처 구분 |
| 검증용 manifest | 현재 후보·revision·headline·asset SHA를 사용자가 토큰 없이 내보낼 수 있는 최소 snapshot 제안. 메모리 Job/세션 접근을 우회하지 않고 최종 다운로드와 대조 가능하게 함 | A, 저장/노출 계약 영향 승인 후 |

ML 학습·feature/scaler·가중치·선호 점수 정의는 B 소유이며 이 목록으로 변경하지 않습니다. 가독성 규칙 통과는 상업적 디자인 품질 승인이나 CTR 예측을 대신하지 않습니다.
