# 3~5분 발표

1. **0:00~0:40** 승인된 주소(현재는 localhost)에 로그인. 실제 모델/Mock 카피 모드 설명. 실물 사용 권한이 있는 상품 사진 또는 E2E가 만드는 합성 병 모양 상품으로 입력. 가게명·상품명·가격 원문 확인.
2. **0:40~1:30** 배경 제거와 원본 비교, 품질이 낮으면 원본 선택. CLIP 단서는 추정이며 사용자 사실이 우선이고 대표색과 구분됨을 설명.
3. **1:30~2:20** 네 전략 Mock 카피 → 1080×1350 광고 네 장 렌더링 → 확대 비교. 카피가 Mock임을 명시. 실제 API는 승인된 설정에서만 사용.
4. **2:20~3:10** 실제 `bt-logistic-v1` 순위, raw score·버전 확인. 상대 선호이며 확률·CTR·성과/객관적 품질 보증이 아님을 설명. 별도 가독성 진단은 규칙/휴리스틱이며 시선 측정이 아님을 설명.
5. **3:10~4:10** 한 후보 문구 편집·재렌더링. revision 증가, 이전 순위 무효화, 재계산. PNG·A4 PDF 다운로드.
6. **4:10~5:00** 모바일 화면, 사용자 사실 보존, 24시간 임시 저장·재시작 유실 한계 설명.

로컬 확인 주소: `http://127.0.0.1:8014`. 외부 URL은 아직 없습니다. [실행·Tunnel 승인 절차](DEPLOYMENT.md)를 따릅니다. 기본 비밀번호를 문서/슬라이드에 게시하지 않습니다.

모델 장애: 오류를 그대로 설명하고 원본 선택·입력·Mock 카피·렌더링·편집·다운로드·진단을 시연합니다. 실제 순위처럼 Mock을 보여주지 않습니다. 의도적인 별도 Mock 실행은 `ranking_mode=mock, require_models=false`를 명시하고 UI의 시연용 안내를 확인합니다.

네트워크 장애: Tunnel을 중지하고 로컬 주소로 전환합니다. localhost 모델·Mock 카피는 인터넷 없이 동작합니다. 서버 재시작은 Job을 잃으므로 먼저 다운로드합니다. 실제 유료 API를 재시도 연타하거나 원장을 초기화하지 않습니다. E2E 결과의 synthetic PNG/PDF·스크린샷은 `artifacts/release/` 아래에 저장하며 Git에 넣지 않습니다.
