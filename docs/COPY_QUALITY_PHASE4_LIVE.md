## 검증 실패의 정확한 해석

네 응답 모두 JSON 구조는 읽을 수 있었지만 **placeholder를 하나도 사용하지 않았다**.
짜장면의 직접 출력 사실은 공백 없는 입력과 같아 기존 검증을 통과했다.

금액 숫자를 바꾼 것은 아니지만 기존 원문/placeholder 계약상 COPY_FACTS_VIOLATION, reason=`rewritten price`다.
입력 가격을 trim하거나 원문에 placeholder를 삽입하는 수작업 교정, 검증 완화, 재호출은 하지 않았다.
에스프레소에는 통과한 bound.json을 만들지 않았다. 실패 원문 자체를 공개·분석했다.

## 광고 목적 효과와 빈 필드

- 메뉴 홍보: 감성 CTA는 선택 권유지만 가격 CTA ‘이 메뉴로 주문해보세요’는 목적 충돌 경고가 발생했다.
- 매장 방문: ‘매장에 들러보세요/직접 보러 오세요/골목반점으로 오세요’로 목적이 가장 잘 드러났다.
  가격 CTA의 ‘들러서 주문’은 방문과 주문을 함께 권한다. 카피 메시지 자체는 다른 목적과 크게 다르지 않다.
- 주문: 감성/가격/브랜드는 주문을 권하지만 비주얼은 ‘지금 골라 보세요’로 남아 목적 충돌이 감지됐다.
- 따라서 목적별 **CTA는 부분적으로 달라졌지만 메시지 전체의 유의미한 차별화는 부족**하다.
- 짜장면은 본문·CTA를 하나도 비우지 않았다. 특히 브랜드/가격은 설명을 비워도 되는 사례인데 반복이 남았다.
- 에스프레소 가격·브랜드의 빈 본문은 불필요한 설명/허위 브랜드 이야기를 줄이는 데 유효했다.
  사진/가격/상호/상품이 별도 표시돼 사실 정보는 빠지지 않았지만, 큰 빈 영역과 약한 CTA 때문에 설득력이 자동으로 좋아진 것은 아니다.
- 검증 통과는 주관적 가격 가치·습관/브랜드 인상까지 사실로 인증한 결과가 아니다. 자동 경고가 없는 비주얼 분석체도 사람이 읽어야 한다.

## 다음 개선 우선순위 (제안만, 이번에 미구현)

1. 가격·상호·상품이 별도 표시되는 구조에서 문구에 사실을 반복하는 부담을 줄이고, 가격 원문은 placeholder로만 연결하도록 설계/지시를 더 명확히 검토한다.
   실패 결과를 통과시키려고 가격을 자동 교정하거나 현재 validator를 완화하지 않는다.
2. 요청마다 선택된 목적의 행동 범위가 두드러지게 전달되도록 지시를 검토한다. 세 목적 지시를 기계적으로 모두 읽히는 것보다 선택 목적에 집중하되 고정 CTA 목록은 만들지 않는다.
3. CLIP 라벨을 그대로 나열하는 문체를 광고 메시지로 바꾸는 긍정적 작문 지침을 보강한다. 금지어만 늘리거나 제공되지 않은 맛을 추가하지 않는다.
4. 근거가 없는 브랜드/가격 본문은 억지 설명보다 생략하고, 실제 상품 특징을 입력한 조건과 비교한다. 특징 없이 차별성을 지어내지 않는다.

**현재 판단은 B안이며 v8 운영 채택/기본값 변경은 하지 않았다.** 다음 수정·추가 호출은 별도 검토가 필요하다.
