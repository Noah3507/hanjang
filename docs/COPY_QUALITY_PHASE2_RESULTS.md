## 치환·최종 표시 문구와 검증

A는 placeholder가 없어 원문과 표시 문구가 동일하다. B의 두 본문만 아래처럼 치환된다.
그 외 모든 headline/body/CTA는 위 원문과 동일하다.

- B price body: 7,000원에 짜장면을 고를 수 있어 식사 메뉴로 부담 없이 맞춥니다. 골목반점에서 오늘 메뉴를 정해보세요.
- B brand body: 골목반점 이름 그대로 골목에서 떠올리기 쉬운 짜장면입니다. 익숙한 한 끼로 자연스럽게 찾게 됩니다.

JSON 파싱·4전략 누락/중복·길이·로컬 검증은 A/B 모두 통과. A에는
COPY_SERVICE_LANGUAGE_REVIEW 경고, B에는 자동 경고 없음. 경고가 없다는 사실은
문구의 자연스러움이나 사실 안전성을 보증하지 않는다. 자동 경고가 못 잡은 B의
어색한 서술과 상호명에서 유추한 설명은 아래에 별도로 기록한다.

치환 후 24개 카피 필드(8장×headline/body/CTA)가 실제 Chromium DOM 계측 텍스트와
모두 일치했다. 각 raw SHA → bound 문구 → PNG SHA → 실제 DOM 계측은
evidence-chain.json에 연결했다. PNG를 직접 열어 시각 검토했으며 OCR을 통한
전 글자 재인식 검사는 하지 않았다. 누락·잘림을 숨기기 위한 수동 수정은 없다.

8. **사용 의향:** AI 판단으로는 제목 일부만 유망하고 원문 전체를 그대로 실매장 SNS 광고로

## 품질을 가장 크게 떨어뜨리는 3가지와 다음 순서

아래는 **후속 제안이며 이번에 구현하지 않았다.** 추가 호출·프롬프트·디자인 변경은 별도 결정한다.

1. **메뉴명을 넣어도 자연스럽고 구체적인 구매 메시지가 부족하다.**
   - P1 프롬프트: 점심/식감/가격/브랜드 전략마다 제목·본문·CTA의 역할을 분리하고
     ‘한 끼 이어가세요/메뉴로 맞춥니다’ 같은 추상 서술 대신 짧은 소비자 언어의 평가 기준을 둔다.
     특징 없는 입력은 새 사실을 만들지 않으며 상호명 이름풀이로 빈 정보를 채우지 않는다.
   - P1 코드·무료 테스트: 실제 실패 문장을 품질 경고 fixture로 보존하고 어색한 서술어,
     의미 중복, 서비스 안내형 CTA를 advisory로 분류한다. 사실 금지어를 마구 추가해 오탐을
     늘리거나 경고마다 자동 유료 재시도하는 방식은 피한다.
