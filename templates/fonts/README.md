# Bundled Korean font

Noto Sans KR Regular, Noto Sans CJK release **Sans2.004**, 4,644,748 bytes.

- Source: https://github.com/notofonts/noto-cjk/tree/Sans2.004/Sans/SubsetOTF/KR
- Download: https://raw.githubusercontent.com/notofonts/noto-cjk/Sans2.004/Sans/SubsetOTF/KR/NotoSansKR-Regular.otf
- SHA256: `69975a0ac8472717870aefeab0a4d52739308d90856b9955313b2ad5e0148d68`
- License: SIL Open Font License 1.1, bundled unchanged in [OFL.txt](OFL.txt).

The regular font is embedded locally as a data URI. Metadata records computed CSS weight and the actually used custom face; a separate bold font file is not bundled. No CDN, runtime font download, or OS font dependency is required. Unsupported glyph fallback is rejected with RENDER_UNSUPPORTED_GLYPH instead of silently emitting inconsistent glyphs. The font is a licensed application asset, not a model weight or user upload.
