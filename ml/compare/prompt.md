# 일반 AI에 넣을 고정 프롬프트

모든 사례에 **아래 문장을 그대로** 써요. 중괄호 `{...}` 부분만 `cases.csv`의 값으로 바꿔요.
일반 AI에게도 우리 서비스가 지키는 규칙(상품 그대로, 정보 정확히, 지어내지 않기)을 똑같이 알려 줘요.
그래야 "일반 AI에게 제대로 부탁해도" 어떤지를 공정하게 비교할 수 있어요.

## 1. 광고 만들기 (사진을 첨부하고 보내기)

```
첨부한 사진 속 상품으로 인스타그램 세로 광고 이미지(4:5 비율, 1080×1350)를 한 장 만들어 주세요.

- 가게명: {store_name}
- 상품명: {product_name}
- 가격: {price_text}
- 분위기: {분위기}
- 광고 목적: {광고 목적}
- 상품 특징: {product_features, 비어 있으면 "없음"}

꼭 지켜 주세요.
1. 사진 속 상품을 다른 모양으로 다시 그리지 말고 사진 그대로 써 주세요.
2. 가게명, 상품명, 가격은 위에 적은 글자 그대로 정확하게 넣어 주세요.
3. 위에 없는 할인, 이벤트, 원산지, 인기 순위, 수상 같은 내용은 넣지 마세요.
```

`mood`와 `ad_goal` 값은 이렇게 바꿔 적어요. 우리 사이트의 선택지 이름과 같아요.

| mood | 분위기 | ad_goal | 광고 목적 |
|---|---|---|---|
| warm | 따뜻한 감성 | menu_promotion | 메뉴 홍보 |
| minimal | 깔끔한 미니멀 | store_visit | 매장 방문 유도 |
| vivid | 활기찬 강렬함 | order | 주문 유도 |
| premium | 고급스러움 | | |

## 2. 가격만 바꾸기 (같은 채팅에서 이어서 보내기)

```
방금 만든 광고에서 가격만 {new_price_text}(으)로 바꿔 주세요. 다른 부분은 하나도 바꾸지 마세요.
```
